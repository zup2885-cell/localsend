# 阿祖快传

阿祖维护的 Mac 文件传输适配版。基于 **LocalSend**，保留原作者 Tien Do Nam、贡献者及 Apache 2.0 许可证。

[下载阿祖的 Mac 版本](https://github.com/zup2885-cell/localsend/releases/latest) · [适配范围与构建说明](ADAPTATION-AZU.md) · [原项目说明](UPSTREAM-README.md)

## 可以做什么

- 在可互通的同一局域网内，向支持 LocalSend 协议的设备发送文件、文件夹和文字。
- 接收端先确认请求，再接收文件；保留原项目的传输加密与确认方式。
- 简体中文默认界面、独立应用标识和阿祖图标，可以与原版分别保存设置。
- 文件选择、接收目录和历史由使用者自己的设备保存；安装包不包含阿祖的文件或收发记录。

收发设备需要网络互通。访客网络隔离、防火墙或系统权限可能影响设备发现。此版本不是云网盘，也不是 LocalSend 官方发布。

## 验证范围

已通过 10 项中文、文件路径和 API 路由测试；本机回环传输 63,488 字节文件，收发 SHA-256 一致。桌面启动、签名与下载包状态见对应 Release。未完成的跨设备场景不会写成已经测试。Mac 安装包使用临时签名，尚无 Apple 公证。
